📖 How the runner works & field map

The login captcha is the only human gate. Once logged in, the extension chains through all 4 pages (entry → main → bank → nominee → success) for every IP in the queue. ~30–45 s per IP. Bank-document + Self-Photo file picks stay manual (browser security); everything else is automated.

See the full field map + master codes in the GitHub repo → src/lib/esic/field-map.ts.
